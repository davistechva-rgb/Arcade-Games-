# Arcade

Nine classic games in one page, with a retro glowing-screen look: **Snake**, **Blocks** (a falling-block puzzle), **Breakout**, **Space Rocks**, **Alien Invasion**, **Paddle Duel**, **Road Hopper**, **Sky Flap**, and **2048**. Keyboard, mouse, and touch controls, high scores saved on the device, sound you can mute, and it works offline once loaded.

Made by [Davis Tech Support](https://davis-tech-support.com) in Farmville, Virginia.

## Controls
| Game | Keyboard | Touch |
| --- | --- | --- |
| Snake | Arrow keys or WASD | Swipe, or the on-screen pad |
| Blocks | Left/Right move, Up or X rotate, Z rotate back, Down soft drop, Space hard drop, C hold | On-screen buttons |
| Breakout | Left/Right or mouse, Space launch | Drag the paddle, tap to launch |
| Space Rocks | Left/Right turn, Up thrust, Space fire | On-screen buttons |
| Alien Invasion | Left/Right move, Space fire | Drag to move, tap to fire, or on-screen buttons |
| Paddle Duel | Up/Down or W/S, or the mouse | Drag your paddle |
| Road Hopper | Arrow keys or WASD | Swipe, or the on-screen pad |
| Sky Flap | Space, Up, or click | Tap |
| 2048 | Arrow keys or WASD | Swipe |

P or Esc pauses. M mutes. Games pause on their own if you switch tabs.

## Deploy
Drag this folder onto Netlify, connect the repository (no build command), use GitHub Pages, or just open `index.html`.
